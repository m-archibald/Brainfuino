USB Connection Troubleshooting

If your Brainfuino or STM32 device does not show up in the port selector:

  1. Check your USB cable: Ensure you are using a full data USB cable. Many charging-only cables omit data lines.
  2. Check Device Manager (Windows): Look under Ports (COM & LPT) for STMicroelectronics Virtual COM Port. If it has a yellow warning icon, re-install the STM32 VCP driver or use Zadig.
  3. Port Conflict / Exclusive Lock: Close any other terminal programs or tools (such as PuTTY, Arduino IDE, STM32CubeProgrammer, or Cura) that may already have the COM port open.
  4. Power Cycle: Unplug and re-plug the USB-C cable to force a clean hardware restart and USB CDC re-enumeration.
  5. Browser Support: Ensure you are using Google Chrome, Microsoft Edge, or Brave over HTTPS, localhost, or local file access with Web Serial permissions enabled.

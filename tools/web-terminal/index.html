Windows Driver / Hardware DFU Help

Manual DFU Entry: Unplug USB-C, place the jumper on the BOOT0 header (pulls BOOT0 HIGH to 3.3V), and reconnect USB-C. Remove or return the jumper to normal position after programming.

Windows WinUSB: If Chrome reports Access Denied, Windows has bound the legacy ST driver. Run Zadig once to assign the WinUSB driver to STM32 BOOTLOADER.

CLI Alternative: pwsh companion-STM32-firmware/build.ps1 -Flash
